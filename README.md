# Single Prompt for Frontend Development

**Presented by:** Munir Khakhi
**Communities:** GDG Rajkot, JS Gujarat

This repository contains the slides and resources for the talk "Single Prompt for Frontend Development: How to build apps with one prompt using Agents".

## 🎤 Abstract

Building frontend applications has evolved. It's no longer just about knowing a framework; it's about navigating the ecosystem and leveraging AI agents to accelerate development. This talk explores how to move from manual coding to orchestration using Single Prompt engineering with AI Agents.

## 📅 Agenda

1.  **📝 Prompt** - The art of asking (PROMPT Framework, RCEO Strategy)
2.  **🤖 Agents** - Your digital workforce
3.  **🛠️ Skills** - Giving agents capabilities
4.  **💻 Commands** - Controlling the flow
5.  **🔧 Tools** - Building the future
6.  **🚀 Live Demo** - Building a functional app

## 🧠 Key Concepts

### The Frontend Stack
*   **Fundamentals:** HTML (Structure), CSS (Design), JavaScript (Logic) - "You can't skip the basics."
*   **Frameworks:** React, Vue, Angular, Tailwind CSS, Sass
*   **Ecosystem:** APIs, State Management, Responsive Design, SEO

### Mastering the Prompt
To get the best results from AI, we use structured frameworks:

**The PROMPT Framework:**
*   **P**ersona - Who is the AI?
*   **R**equest - What do you want?
*   **O**utput - How should it look?
*   **M**odifiers - Constraints/Style
*   **P**urpose - Why are we doing this?
*   **T**ech Stack - Tools & Libraries

**RCEO Strategy:**
*   **R**ole (e.g., Senior Frontend Engineer)
*   **C**ontext (e.g., Building a dashboard with Next.js)
*   **E**xample (e.g., Create a responsive Sidebar)
*   **O**utput (e.g., Clean React code with TypeScript)

### The New Workflow
*   **🤖 Agent:** An autonomous AI entity that plans and executes tasks.
*   **🛠️ Skill:** Capabilities given to an agent (browsing, file editing, git).
*   **💻 Command:** Instructions that trigger specific agents or workflows (e.g., `/refactor`).
